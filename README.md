# Event Ticketing & Seat Booking Platform

### Online platform for event management, seat selection, and ticket booking.

---

## 1. Project Overview

The **Event Ticketing & Seat Booking Platform** is an online system that allows customers to browse events, check seat availability, select seats, and book tickets.

The system provides separate functionalities for **Admin, Customer, and Event Organizer** to manage events, venues, seats, bookings, and tickets efficiently.

---

## 2. Problem Statement

Traditional event ticket booking can be time-consuming and may require users to visit ticket counters or use different booking platforms.

Users may also face difficulties in checking available seats and selecting their preferred seats in real time.

This project provides an online solution where users can view events, check available seats, select their preferred seats, and book tickets without manual intervention.

## 6. User Roles

### Admin

- Manage users
- Add, update, and delete events
- Manage venues and seats
- View bookings
- Manage ticket availability
- View payment information

### Customer/User

- Register and login
- Browse available events
- View event details
- Check seat availability
- Select seats
- Book tickets
- Make payment
- View booking history
- Cancel bookings
- View tickets

### Event Organizer

- Create and update event details
- Manage event schedules
- View bookings
- Monitor ticket availability
